# OC Orden Creativo 🚀

Landing page del estudio creativo OC Orden Creativo.
Diseño, automatización IA, audiovisuales y marketing digital.

## 📁 Estructura del proyecto

- `index.html` - Página principal
- `style.css` - Estilos CSS
- `script.js` - Interactividad JavaScript

## 🚀 Despliegue en GitHub Pages

1. Sube los archivos a un repositorio en GitHub
2. Ve a Settings > Pages
3. Selecciona la rama `main` y el directorio `/ (root)`
4. Guarda y espera unos minutos

## 🎨 Tecnologías

- HTML5
- CSS3
- JavaScript (vanilla)
- Google Fonts (Inter, Playfair Display)
- Sin dependencias externas
