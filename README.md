# OC Orden Creativo 🚀

Landing page del estudio creativo OC Orden Creativo.
Diseño, automatización IA, audiovisuales y marketing digital.

## 📁 Estructura del proyecto

- `index.html` - Página principal
- `style.css` - Estilos CSS
- `script.js` - Interactividad JavaScript
- `.nojekyll` - Configuración para GitHub Pages

## 🚀 Despliegue en GitHub Pages

### Opción 1: Script automático
```powershell
.\deploy.ps1
```

### Opción 2: Manual

```bash
git init
git remote add origin https://github.com/TU_USUARIO/oc-orden-creativo.git
git push -u origin master
```

Luego en GitHub:
1. Ve a **Settings > Pages**
2. Source: **Deploy from a branch**
3. Branch: **master**, Folder: **/** (root)
4. Guarda

Tu sitio estará disponible en: `https://TU_USUARIO.github.io/oc-orden-creativo`
